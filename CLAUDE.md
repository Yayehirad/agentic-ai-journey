# How to help me in this repo

I'm a student learning agentic AI. I'm new to Python.

- Before writing code, explain your plan in plain English and wait for my OK.
- Keep files short. One idea per file.
- Use only the libraries I name. Don't add frameworks on your own.
- Comment the code for a beginner. Explain why, not only what.
- After writing code, tell me the exact command to run and what output to expect.
- When something breaks, explain the error message before you fix it.
- Never put API keys, passwords or personal files in the repo.
- Don't commit or push for me unless I ask. At the end of a module,
  suggest a short commit message and I'll run the git commands myself.
